ต้องทำอะไรต่อ

Step 1
สร้าง GitHub repoสร้าง repo เช่น `Boutikhomes-Workspace` แล้วอัปโหลดไฟล์ชุดนี้ขึ้น branch `main`
Step 2
เปิด GitHub Pagesไปที่ Settings → Pages → Deploy from branch → เลือก `main` และ `/root`
Step 3
ใส่ URL ของแต่ละระบบเมื่อ Sales CRM หรือ Dashboard deploy แล้ว ให้เปลี่ยนลิงก์ใน card จาก placeholder เป็น URL จริง
Step 4
ค่อยเชื่อม Googleเฉพาะระบบที่ต้องอ่าน/เขียน Google Sheet หรือเช็กสิทธิ์อีเมล จึงค่อยใช้ Apps Script หรือ backend
